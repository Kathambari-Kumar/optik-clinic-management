# Oves Optik – Clinic Booking & Prescription Management System

A full-stack web application developed during a **Backend & Frontend Developer Internship (LIA)** for **Oves Optik** (Finspång, Sweden) to streamline daily optical clinic operations, customer appointment scheduling, and prescription management.

## Overview
Built in collaboration with the clinic owner to replace manual workflows with a centralized, user-friendly digital system. The application supports front-desk scheduling, structured patient prescription records, and real-time operational reporting.

## Key Features
* **Appointment Booking System:** Interactive scheduling workflow allowing staff to book, update, and manage customer eye examination appointments.
* **Prescription Management:** Structured relational storage and retrieval for optical prescriptions and customer history.
* **Real-Time Analytics Dashboards:** Visual dashboards displaying daily bookings and operational metrics to support business decisions.
* **Client-Driven Iteration:** Refined through regular requirements gathering and live demonstrations with the business owner.

## My Contributions
* Developed and maintained full-stack features using **React, Node.js, and PostgreSQL** in a production environment.
* Designed and implemented RESTful API endpoints and relational database schemas for booking and prescription workflows.
* Built real-time data visualization dashboards and delivered live client demonstrations to gather stakeholder feedback.
* Participated across the full software development lifecycle, including requirements gathering, implementation, testing, debugging, and technical documentation.
